Traffic Protection Service ()
Definition: Traffic Protection Service ABB is a Technology Service that protects applications and digital public services from malicious and abusive network/application traffic. It provides capabilities such as DDoS mitigation, web application firewalling, traffic filtering (L3–L7), rate limiting, bot protection, IP reputation controls, and enforcement of edge access/security policies.
