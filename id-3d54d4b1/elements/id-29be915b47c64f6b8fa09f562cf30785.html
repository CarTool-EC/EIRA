Credential Issuance Service ()
Definition: Credential Issuance Service ABB is an Application Service that issues Verifiable Credentials to a Holder, including policy evaluation, credential generation, cryptographic signing, and delivery to a wallet through standard protocols. Source: Inspired by W3C Verifiable Credentials Last modification: 2026-02-04 Identifier: http://data.europa.eu/dr8/CredentialIssuanceServiceApplicationService LOST view: Technical view - application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:CredentialIssuanceServiceApplicationService Synonym: Issuance Service Example: An issuance endpoint that delivers a signed Residence credential to the citizen’s wallet using standard issuance protocols supported by EUDI Wallet ecosystems. Interoperability Saliency: Enables interoperable issuance across Member States by relying on shared credential models and standard signing / exchange mechanisms.
