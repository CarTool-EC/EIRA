Request Validation Service ()
Definition: Request Validation ABB is a technology service that inspects, evaluates, and enforces security, compliance, and interoperability policies on inbound and outbound digital service requests before they are processed by applications or data services. Last modification: 2026-01-26 Identifier: http://data.europa.eu/dr8/RequestValidationTechnologyService LOST view: Technical view – infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:RequestValidationTechnologyService Additional identifier: http://data.europa.eu/dr8/RequestValidationTechnologyService Synonym: API Gateway Policy Enforcement, Security Filter , Policy Enforcement Point (PEP) Example: AWS API Gateway authorizers, Azure API Management policies, Istio Policy Enforcement Interoperability Saliency: Request Validation ensures that only authorized, correctly structured, and policy-compliant requests are allowed to cross organisational and national boundaries, enabling trusted cross-border digital public services. Additional information: This ABB enforces security, semantic, and protocol policies independently of any specific digital public service. EIF Layer: TechnicalInfrastructure
