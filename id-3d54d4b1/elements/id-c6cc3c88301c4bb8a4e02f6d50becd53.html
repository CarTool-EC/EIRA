Credential Revocation Service ()
Definition: Credential Revocation Service ABB is an Application Service that provides credential status information and supports publishing/updating status entries to enable reliable verification decisions. Last modification: 2026-02-04 Identifier: http://data.europa.eu/dr8/CredentialRevocationServiceApplicationService LOST view: Technical view - application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:CredentialRevocationServiceApplicationService Synonym: Credential Status Service Example: A status endpoint queried by verifiers to confirm that a credential has not been revoked before granting service access. Interoperability Saliency: Enables cross-border trust by ensuring validity check of credentials beyond signature verification.
