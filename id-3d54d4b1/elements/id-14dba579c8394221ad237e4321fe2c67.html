Credential Revocation ()
Definition: Credential Revocation ABB is an Application Component that manages credential status (revoked/suspended/valid) and exposes status information required for verifiers to determine whether a credential remains trustworthy. Last modification: 2026-02-04 Identifier: http://data.europa.eu/dr8/CredentialRevocationApplicationComponent LOST view: Technical view - application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:CredentialRevocationApplicationComponent Synonym: Credential Status Manager Example: A revocation registry that marks a credential as revoked after loss/theft and allows verifiers to check status during verification. Interoperability Saliency: key for interoperability and trust because verification across borders requires a consistent way to evaluate credential validity over time.
