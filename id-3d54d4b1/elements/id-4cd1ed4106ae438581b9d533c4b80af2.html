Log Collection Service ()
Definition: Log Collection Service ABB is a technology service that collects log records emitted by infrastructure, platforms, and applications, normalizes/enriches them, and forwards them to storage and analysis capabilities. Source: Industry standard (observability and log management) Last modification: 2026-02-02 Identifier: http://data.europa.eu/dr8/LogCollectionServiceTechnologyService LOST view: Technical view - infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:LogCollectionServiceTechnologyService Synonym: Log Ingestion Service Example: ELK Stack , AWS Cloud Watch , Azure Monitor, Google cloud logging Interoperability Saliency: Enables interoperable operations by ensuring logs can be collected consistently across implementations and organisations, supporting incident management, troubleshooting, and accountability. Additional information: The scope of this ABB is ingestion/collection.
