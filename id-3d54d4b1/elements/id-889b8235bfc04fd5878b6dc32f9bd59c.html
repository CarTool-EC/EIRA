API Contract Service ()
Definition: The API Contract Service ABB is a technology service that defines and publishes formal interface contracts for APIs (operations/endpoints, request/response structures, error models, security requirements and versioning). It enables consistent implementation and validation of interfaces across different providers and platforms, supporting interoperable digital public services.
