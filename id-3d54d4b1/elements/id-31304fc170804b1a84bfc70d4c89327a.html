Vocabulary ()
Definition: Vocabulary ABB, a Data Object, is a basic, reusable and extensible data specification that captures the fundamental characteristics of an entity in a context-neutral fashion. Its main objective is to provide terms to be reused in the broadest possible context. Source: SEMIC Source reference: https://semiceu.github.io/style-guide/1.0.0/terminological-clarifications.html#sec:what-is-a-cv-specification Last modification: 2024-01-28 Identifier: http://data.europa.eu/dr8/VocabularyDataObject LOST view: Semantic view EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:VocabularyDataObject Interoperability Saliency: The Vocabulary ABB is salient for semantic interoperability because it provides a shared and reusable set of terms that enable consistent interpretation of data across systems and domains. By defining concepts and relationships in a context-neutral and extensible manner, it supports cross-border and cross-sector data exchange while reducing ambiguity and duplication of semantic specifications. Example: An example Vocabulary is the set of Core Vocabularies maintained by SEMIC. SEMIC Core Vocabularies are reusable, extensible semantic specifications that define fundamental concepts and relationships for cross-border and cross-sector digital public services in Europe. Examples include: 1) Core Person Vocabulary – defines the main characteristics of a person (e.g., name, identifier, birth date); 2) Core Business Vocabulary – defines the main characteristics of a legal entity or organisation. and several more. Additional information: A Vocabulary (or Core Vocabulary), as defined in the SEMIC context, typically encompasses: A lightweight ontology defining core concepts and relationships; Optionally, a permissive data shape specification that constrains how the vocabulary is used in practice; A consolidated data specification document that supports reuse in the broadest possible context.
