Semantic Specifications Enablers ()
Definition: Semantic Specifications Enablers ABB is a Grouping that refers to a set of conceptual artefacts that define the meaning, structure, constraints and relationships of data exchanged within digital public services. These artefacts provide the formal or semi-formal specifications that ensure shared understanding of information across organisational and sectorial boundaries.
