Message Broker ()
Definition: Message Broker ABB is a technology service that enables asynchronous communication between distributed applications by receiving, routing, transforming, and delivering messages. It supports decoupling of producers and consumers, message buffering, reliable delivery, and event-driven integration without embedding business logic. Last modification: 2026-01-15 Identifier: http://data.europa.eu/dr8/MessageBrokerTechnologyService LOST view: Technical view infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:MessageBrokerTechnologyService Additional identifier: http://data.europa.eu/dr8/MessageBrokerTechnologyService Synonym: Event Broker; Messaging Middleware; Pub/Sub Broker Example: Apache Kafka , RabbitMQ , Azure Service Bus , AWS SNS/SQS , Google Pub/Sub , ActiveMQ Interoperability Saliency: The Message Broker ABB is salient for technical interoperability because it enables loosely-coupled, asynchronous data exchange between heterogeneous digital services across organisations and Member States. It supports standard messaging protocols and event-driven architectures, allowing independent systems to interoperate without requiring direct point-to-point integrations, thereby improving scalability, resilience, and cross-border data exchange. Additional information: Message brokers provide transport-level decoupling between producers and consumers and are typically used to implement event-driven, microservice-based, and integration-oriented architectures.
