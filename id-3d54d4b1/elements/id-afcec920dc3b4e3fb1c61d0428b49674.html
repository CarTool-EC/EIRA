Protocol Mediation Service ()
Definition: Protocol Mediation Service ABB is a Technology service that enables interoperability between systems using different communication protocols by mediating protocol-specific interaction patterns, message exchange modes, and transport-level requirements. Source: Industry practice (integration/middleware) Last modification: 2026-02-02 Identifier: http://data.europa.eu/dr8/ProtocolMediationServiceTechnologyService LOST view: Technical view - infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:ProtocolMediationServiceTechnologyService Synonym: Protocol Gateway Service , Transport Mediation Service Example: Bridging a SOAP/HTTP interface exposed by a legacy service to a REST/HTTP API consumed by a modern application , mediating between a file-based exchange (SFTP) and an API-based exchange (HTTPS) for document delivery. Interoperability Saliency: This ABB is salient for technical interoperability because it enables organisations to interconnect systems that cannot natively communicate using the same protocol, without forcing uniform technology adoption.
