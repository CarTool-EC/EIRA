Self-Soverign Identity ()
Definition: Self-Sovereign Identity (SSI) ABB is an Application Component that enables decentralized, user-controlled digital identity by supporting the issuance, holding, presentation, verification, and lifecycle management of digital credentials using standardized data models and cryptographic mechanisms, minimizing dependence on centralized identity providers. Source: Inspired by SSI and Verifiable Credentials reference patterns Last modification: 2026-02-05 Identifier: http://data.europa.eu/dr8/SelfSovereignIdentityApplicationComponent LOST view: Technical view – application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:SelfSovereignIdentityApplicationComponent Synonym: Decentralized Identity Example: EUDI Wallet-compatible implementations Interoperability Saliency: The SSI ABB is salient for technical interoperability because it enables cross-domain and cross-border identity interactions using common credential formats and verification mechanisms, allowing a credential issued in one Member State or sector to be verified and trusted by services in another without point-to-point integrations. Additional information: This ABB abstracts the SSI capability set at reference architecture level Interoperability Dimension: Structural IoP Additional identifier: http://data.europa.eu/dr8/SelfSovereignIdentityApplicationComponent EIF Layer: TechnicalApplication
