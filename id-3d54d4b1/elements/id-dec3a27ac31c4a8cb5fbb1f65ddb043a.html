Data Exposure Enablers ()
Definition: Data Exposure Enablers ABB is a Grouping that refers to a set of data publication and dissemination models that determine how data and knowledge are made available for access, reuse and integration across organisational and sectorial boundaries. These enablers define the conditions, principles and patterns under which data is exposed, such as openness, linking and event-driven dissemination. Source: Inspired by Open Data Directive and Linked Data principles.
