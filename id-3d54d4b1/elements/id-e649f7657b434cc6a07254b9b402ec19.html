DID Resolver ()
Definition: DID Resolver ABB is an Application Component that resolves Decentralized Identifiers (DIDs) into DID Documents to obtain public keys, service endpoints, and verification material needed for credential validation. Source: W3C DID architecture Last modification: 2026-02-04 Identifier: http://data.europa.eu/dr8/DIDResolverApplicationComponent LOST view: Technical view - application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:DIDResolverApplicationComponent Synonym: DID Resolver Example: Resolving an issuer DID to retrieve the public key used to validate a credential signature. Interoperability Saliency: Supports interoperability by providing a standard method to obtain verification material Interoperability Dimension: Structural IoP Additional identifier: http://data.europa.eu/dr8/DIDResolverApplicationComponent EIF Layer: TechnicalApplication
