Digital Identity Wallet ()
Definition: Digital Identity Wallet ABB is a Application Component controlled by the user (Holder) that stores, manages, and presents digital identity data and Verifiable Credentials. Source: EU Digital Identity Wallet Last modification: 2026-02-04 Identifier: http://data.europa.eu/dr8/DigitalIdentityWalletApplicationComponent LOST view: Technical view - application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:DigitalIdentityWalletApplicationComponent Synonym: EUDI Wallet Example: A citizen mobile wallet that stores “Driving licence credential” and presents it to a verifier for an online public service. Interoperability Saliency: Ensures user-centric, interoperable identity presentation by supporting standard credential formats and verifiable presentations across Member States.
