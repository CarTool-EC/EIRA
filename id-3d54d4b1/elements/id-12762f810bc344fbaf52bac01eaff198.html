Access Management Platform ()
Definition: Access Management Platform ABB is a System Software that enforces access control decisions across digital services and applications by evaluating authentication and identity information and applying authorisation policies, session management, and access enforcement mechanisms consistently across the platform. Source: Inspired in eIDAS, OAuth 2.0, OpenID Connect Source reference: https://digital-strategy.ec.europa.eu/en/policies/eidas-regulation Last modification: 2026-01-26 Identifier: http://data.europa.eu/dr8/AccessManagementPlatformSystemSoftware LOST view: Technical view - infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:AccessManagementPlatformSystemSoftware Interoperability Dimension: Structural IoP Interoperability Saliency: Access Management Platform ABB is salient for technical interoperability because it enforces consistent authorisation policies and session management mechanisms across multiple platforms and services, ensuring that only authenticated and authorised stakeholders can access digital resources. Example: The following implementation is an example of how this specific Architecture Building Block (ABB) can be instantiated as a Solution Building Block (SBB): Keycloak is an open-source identity and access management solution that provides token-based authorisation, SSO session lifecycle management, and integration with LDAP and Active Directory. Additional information: Typical capabilities include authorisation policy evaluation, token validation, session lifecycle management, and integration with identity sources such as Identity Providers, Federated Identity Providers, and directory services (LDAP, Active Directory).
