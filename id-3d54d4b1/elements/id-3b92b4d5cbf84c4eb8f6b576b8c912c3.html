Pipeline Service ()
Definition: Pipeline service ABB is a technology service that automates the integration, build, security validation, testing and delivery of software changes, producing versioned and traceable release outputs for deployment into target environments. Source: Industry DevOps practices Last modification: 2026-02-03 Identifier: http://data.europa.eu/dr8/PipelineTechnologyService LOST view: Technical view – infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:CICDPipelineTechnologyService Synonym: continuous integration, continuous delivery, build pipeline, deployment pipeline Example: GitHub Actions ,GitLab CI/CD, Jenkins Pipelines, Azure Pipelines Interoperability Saliency: Enables interoperable software delivery by enforcing repeatable, auditable and standardised build and deployment pipelines across infrastructures. Additional information: This ABB covers pipeline automation and governance, not runtime execution of workloads.
