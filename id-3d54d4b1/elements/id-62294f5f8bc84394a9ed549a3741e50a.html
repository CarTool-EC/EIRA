Directory Service ()
Definition: Directory Service ABB is a technology service that provides standardized access to identity, account, and attribute information stored in directory repositories for authentication, authorization, and identity federation purposes. Last modification: 2026-01-26 Identifier: http://data.europa.eu/dr8/DirectoryService LOST view: Technical view – Infrastructure EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:DirectoryService Additional identifier: http://data.europa.eu/dr8/DirectoryService Synonym: Identity Directory , Account Directory Example: LDAP , Active Directory Domain Services, Azure AD Domain services, OpenLDAP Directory Interoperability Saliency: Directory Service enables cross-system and cross-border interoperability by providing a standardized way to retrieve and manage identity and attribute data independently of specific directory products.
