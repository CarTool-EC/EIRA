Digital Identity Wallet Service ()
Definition: Digital Identity Wallet Service ABB is a Application Service that enables a user to store, manage, and present Verifiable Credentials and identity attributes. Source: W3C Verifiable Presentations and standard SSI wallet usage patterns. Last modification: 2026-02-04 Identifier: http://data.europa.eu/dr8/DigitalIdentityWalletServiceApplicationService LOST view: Technical view - application EIRA concept: eira:ArchitectureBuildingBlock ABB name: eira:DigitalIdentityWalletServiceApplicationService Synonym: Credential Storage & Presentation Service , Holder Service Example: Presenting a 'Proof of Age' from the wallet to a service provider using a verifiable presentation. Interoperability Saliency: Improves cross-border interoperability by using shared presentation patterns and credential formats so verifiers can validate consistently. Additional information: Typically consumes Credential Verification Service and may interact with Credential Issuance Service to receive new credentials.
